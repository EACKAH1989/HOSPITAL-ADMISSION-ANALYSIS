Hospital Admissions Analysis Using SAS

Overview

This project uses SAS to analyze hospital admissions data, focusing on patient characteristics, hospital utilization, diagnoses, length of stay, and in-hospital mortality.

Analysis

The project includes:

* Data cleaning and preparation
* Descriptive statistics
* Hospital length-of-stay calculation
* Emergency department utilization analysis
* Categorical and continuous variable analysis
* In-hospital mortality analysis
* Logistic regression

Tools

* SAS 9.4
* SAS DATA Step
* PROC CONTENTS
* PROC MEANS
* PROC FREQ
* PROC TTEST
* PROC LOGISTIC

Key Variables

* Admission type and location
* Insurance
* Ethnicity
* Diagnosis
* Length of stay
* Emergency department time
* In-hospital mortality
